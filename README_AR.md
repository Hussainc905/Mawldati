# مولدتي - Mawldati Android v0.2

تطبيق Android تابع لـ ELYAS-TECH ومربوط بنظام التراخيص في Supabase.

## الجديد في v0.2

- شاشة التفعيل تظهر فقط عند الحاجة.
- فحص الاشتراك تلقائيًا عند تشغيل التطبيق.
- واجهة رئيسية بعد نجاح الترخيص.
- عرض حالة الاشتراك: فعال / تجريبي / دون إنترنت.
- عرض تاريخ البداية والانتهاء والأيام المتبقية.
- زر فحص الاشتراك يدويًا.
- زر الاتصال بالدعم الفني.
- زر نسخ معرف الجهاز.
- تغيير رمز التفعيل بعد تأكيد المستخدم.
- استمرار مهلة العمل دون إنترنت حسب إعداد Supabase.

## البناء على GitHub

المشروع مجهز بـ GitHub Actions. عند رفع الملفات إلى فرع `main` يبدأ البناء تلقائيًا.

1. افتح **Actions**.
2. اختر **Build Mawldati Android APK**.
3. بعد نجاح التشغيل افتح آخر Run.
4. من **Artifacts** حمّل `Mawldati-v0.2-debug-apk`.
5. فك الضغط وثبّت `app-debug.apk`.

## تحديث Supabase الاختياري الموصى به

شغّل الملف `supabase_v0_2.sql` مرة واحدة داخل Supabase SQL Editor حتى يستطيع التطبيق إظهار اسم العميل واسم المولدة وتاريخ بداية الاشتراك.
