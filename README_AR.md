# مولدتي — Mawldati v0.3.6

تطبيق Android لإدارة المولدات، يعمل على الهاتف والتابلت، ومربوط بنظام ترخيص Supabase.

## سجل التعديلات
- v0.3.1: دعم التابلت Android وتخطيط الشاشات الكبيرة.
- v0.3.2: البحث السريع عن المشترك بالاسم.
- v0.3.3: قائمة مشتركين مرقمة مع الأمبير وحالة الدفع بالأخضر/الأحمر.
- v0.3.4: إرسال مباشر إلى واتساب عبر WhatsApp Business Platform.
- v0.3.5/v0.3.6: وصل رسمي مصور، رقم تسلسلي من السيرفر، QR للتحقق، سجل إلغاء، وأيقونة مولدة جديدة.

## الوصل الرسمي
عند دفع المشترك:
1. التطبيق يطلب رقم وصل من Supabase.
2. Supabase ينشئ رقمًا فريدًا مثل `ELY-2026-000001` ويحفظ نسخة سجل غير قابلة للتعديل من التطبيق.
3. التطبيق يرسم وصل PNG رسميًا مع اللوكو والتفاصيل وQR.
4. الوصل يرسل مباشرة إلى رقم واتساب المحفوظ للمشترك عبر Edge Function.
5. إذا ألغي الدفع، يبقى الوصل محفوظًا في السيرفر ولكن حالته تصبح `cancelled`.

راجع `RECEIPT_SETUP_AR.md` لإعداد Supabase وWhatsApp.
