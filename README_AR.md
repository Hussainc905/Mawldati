# مولدتي v0.3.0 — ELYAS-TECH

هذه النسخة تنقل التطبيق من شاشة الترخيص فقط إلى تطبيق إدارة مولدة فعلي.

## الجديد في v0.3.0
- واجهة رئيسية بعد التفعيل مع ملخص مباشر.
- إدارة المشتركين: اسم، هاتف، منطقة، أمبيرات، اشتراك شهري.
- الجباية الشهرية: مدفوع / غير مدفوع، المبلغ المستلم، إلغاء الدفع.
- مشاركة إيصال نصي عبر واتساب أو تطبيقات المشاركة.
- إدارة المصروفات الشهرية.
- تقرير الشهر: المتوقع، المقبوض، المتبقي، المصروفات، الصافي.
- صفحة مستقلة للاشتراك والترخيص.
- صفحة إعدادات ودعم ومعرف الجهاز.
- البيانات التشغيلية محفوظة محلياً على الجهاز في هذه المرحلة.
- نظام Supabase للترخيص بقي كما هو.

## ملاحظة
الإصدار التالي يمكن أن يضيف مزامنة بيانات المشتركين إلى السحابة، نسخة احتياطية، وإيصال كصورة واتساب.
