# مولدتي v0.3.7

نسخة إدارة المولدات مع وصل رسمي وإرسال مباشر إلى واتساب المشترك.

## التعديلات المتراكمة
- v0.3.1: دعم التابلت Android.
- v0.3.2: البحث عن المشترك بالاسم.
- v0.3.3: قائمة مشتركين مرقمة مع الأمبير وحالة الدفع.
- v0.3.4: تجهيز الإرسال المباشر إلى واتساب عبر WhatsApp Business Platform.
- v0.3.6: وصل رسمي ورقم تسلسلي من السيرفر وأيقونة مولدة.
- v0.3.7: إلغاء QR نهائياً من الوصل ومن مسار التشغيل؛ يبقى رقم الوصل التسلسلي محفوظاً في Supabase كمرجع رسمي، ويرسل الوصل كصورة مباشرة إلى رقم واتساب المشترك.

## ملاحظة
لا تحتاج دالة `verify-receipt` ولا تحتاج أي إعداد QR. المطلوب فقط نشر `send-whatsapp-receipt` وضبط أسرار WhatsApp Cloud API.
